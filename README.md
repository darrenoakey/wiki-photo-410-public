# Hornsby railway station, circa 1900

A single-page public static projection of the Hornsby local-history Wiki record. Audience: public. The bundle contains one historical photograph, a concise excerpt, and an explicit JSON audience manifest; it contains no private wiki record identifiers or family material.

The photograph “Hornsby railway station circa 1900.jpg” is from Wikimedia Commons and is marked Public domain. The source file and attribution are linked from the page.

The page is hosted as static files on GitHub Pages because the configured Cloudflare credentials were denied Pages and Worker asset writes (HTTP 403). The page itself requires no application server or API. A free GitHub-hosted Playwright check opens it in an iPhone 13 viewport over a cellular-like network profile from outside the home network; this is a remote device emulation, not a physical phone.
